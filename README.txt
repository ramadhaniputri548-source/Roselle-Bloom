# Roselle Bloom — Website UTS Digitalisasi UMKM

## Isi folder
- `index.html`: halaman Home, About, Product, Gallery, dan Contact.
- `style.css`: desain website dan tampilan responsive.
- `script.js`: interaksi menu mobile, tombol kembali ke atas, dan tahun otomatis.

## Menjalankan website
1. Ekstrak file ZIP ini.
2. Buka folder `roselle-bloom` melalui VS Code (File > Open Folder).
3. Pastikan extension Live Server terpasang.
4. Klik kanan `index.html` > Open with Live Server.
